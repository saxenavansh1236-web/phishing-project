How to use it

  1. Load the extension from chrome://extensions (Developer mode, Load unpacked).
  2. Open its Settings, paste your server address and this key, then Save.
  3. Scan the current page, or right-click any link and choose "Scan link with PhishGuard".

Or call the API directly:

curl -X POST http://127.0.0.1:5000/api/v1/scan \
  -H "X-API-Key: pg_your_key" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com"}'
